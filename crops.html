Crop reference list

The crops PhenoBase accepts observations for, with common names in English, Korean, Japanese and Chinese, the accepted scientific name and the stage scale used to record them. To add a crop, open a request on the issue tracker with the scientific name and the countries where it will be observed.

Scientific names are working names, to be checked against Plants of the World Online (POWO) by the taxonomic editor before release 1.0. Names in other languages are the common market or agricultural names; regional names should be added by country coordinators.
